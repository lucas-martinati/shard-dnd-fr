# Corpus D&D 2014

Ce dossier réunit le corpus historique de compatibilité, par catégorie. Il regroupe les traductions provenant du Shard Player’s Guide Volume 1, des anciennes références SRD, des extraits utilisateur et des dictionnaires historiques.

Le guide Shard repose majoritairement sur l’ancien SRD ; les sources précises restent indiquées dans les traductions. Ce regroupement n’est pas une déclaration de couverture complète du PHB 2014. Les libellés utilisables dans plusieurs éditions gardent leur édition `any` et sont réutilisés en 2024 lorsque leur anglais est identique. Les règles explicitement 2024 restent avec le PHB ou le MM 2024.

Voir [le suivi](../../audit/livres/2014.json) et [la méthode de classement](../../audit/classement.json).
