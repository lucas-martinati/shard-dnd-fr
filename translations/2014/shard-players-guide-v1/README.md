# Shard Player’s Guide Volume 1 : équipement et objets magiques

Les packs `objets/traductions.json` et `regles/traductions.json` complètent les traductions communes déjà présentes. Ils couvrent les textes propres aux chapitres Équipement et Objets magiques ainsi que les variantes des fiches liées. Un nom partagé n’est pas recopié lorsqu’il est déjà connu.

Le relevé du 16 octobre 2026 est conservé dans `tests/fixtures/shard-players-guide-v1.json` : deux chapitres, 239 notices d’objets magiques et 1 372 fiches de la liste d’équipement. Le rapport utilisateur de 122 manques est reproduit dans `tests/fixtures/guide-equipment-report-11736.json`.

Source consultée : [Shard Player’s Guide Volume 1](https://play.shardtabletop.com/#book?id=bi5f3lrxndk004tpyc0rt&cid=q4qshq492a8l16u0). Le classement dans le corpus historique ne vaut pas attribution exclusive au PHB 2014. Les autres chapitres du guide ne sont pas validés par ce relevé.

Les correspondances issues du [Document de référence du système 5.1 français](https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1_FR.pdf), © Wizards of the Coast LLC, sont utilisées sous [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Les adaptations conservent les valeurs, unités, exceptions et découpages de l’anglais affiché par Shard ; elles ne remplacent pas une règle ancienne par son équivalent 2024. Les entrées indiquent leur provenance et les compléments traduits depuis le relevé sont identifiés séparément.

Les poids restent dans les unités d’origine. Les liens, dés interactifs et tableaux sont contrôlés sur le HTML relevé, avec restauration de l’anglais lors de la désactivation.

Le livre contient lui-même quelques fragments incomplets ou déplacés, notamment dans les notices des robes des étoiles et des yeux. Les correspondances suivent le texte affiché sans lui substituer une autre édition des règles.
