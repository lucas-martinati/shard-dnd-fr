# Correspondances à classer

Ces traductions sont utilisées par le script, mais leur livre et leur édition ne sont pas établis. La majorité provient de noms relevés dans le catalogue d’armes sans indication de livre sur les lignes de la liste.

Déplacer une entrée lorsqu’une fiche ou une source permet de la rattacher à un livre. Ne pas inventer ce rattachement à partir d’un nom. Voir [la méthode de classement](../../audit/classement.json).
