# Compatibilité avec les anciens contenus

Le `shard-player-guide-volume-1/` conserve son propre ensemble de traductions. `commun/` contient les règles 2014 et les dictionnaires historiques non propres à ce guide.

Ces fichiers restent chargés afin de préserver les traductions existantes. L’emplacement d’un dictionnaire historique indique son origine et son rôle de compatibilité : certains noms et termes sont aussi valables en 2024. Les nouveaux ajouts ciblent d’abord les livres 2024.
